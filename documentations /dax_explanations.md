DAX Measures – Detailed Explanations

1. Sales Performance Analysis

Total Boxes

Total Boxes =
SUM('Shipments'[Boxes])

Calculates the total number of boxes sold.

Total Shipments

Total Shipments =
DISTINCTCOUNT('Shipments'[Shipment ID])

Counts unique shipments.

Boxes Per Shipment

Boxes Per Shipment =
DIVIDE([Total Boxes], [Total Shipments], 0)

Calculates the average boxes per shipment.

Amount Per Shipment

Amount Per Shipment =
DIVIDE([Total Amount], [Total Shipments], 0)

Calculates the average sales amount per shipment.

2. Employee Performance Analysis

Beverie Moffett's Total Sales

Beverie Moffett =
CALCULATE(
    [Total Amount],
    'Shipments'[Sales_person] = "Beverie Moffett"
)

Calculates the total sales generated by Beverie Moffett.

Beverie Moffett's Bars Sales

Beverie Moffett Bars =
CALCULATE(
    [Total Amount],
    'Shipments'[Sales_person] = "Beverie Moffett",
    'Shipments'[Product Category] = "Bars"
)

Calculates her sales from the Bars category.

Beverie Moffett's Sales Contribution

Beverie Moffett Sales Contribution =
DIVIDE(
    [Beverie Moffett],
    [Total Amount],
    0
)

Calculates her percentage contribution to overall sales.

4. Sales Target Analysis

Sales Target

Sales Target = 2000000

Defines the target as ₹20,00,000.

Target Achievement Status

Target Achievement Status =
IF(
    [Total Amount] >= [Sales Target],
    "Target Achieved",
    "Target Failed"
)

Sales Performance Category

Sales Performance Category =
SWITCH(
    TRUE(),
    [Total Amount] < 1000000, "Low",
    [Total Amount] <= 2000000, "Medium",
    "High"
)

Category| Sales
Low| Below ₹10,00,000
Medium| ₹10,00,000–₹20,00,000
High| Above ₹20,00,000

5. Employee Ranking Analysis

Employee Sales Rank

Employee Sales Rank =
RANKX(
    ALL('Shipments'[Sales_person]),
    [Total Amount],
    ,
    DESC,
    DENSE
)

Ranks employees based on total sales.

Top 3 Employee Classification

Top 3 Employee Classification =
IF(
    [Employee Sales Rank] <= 3,
    "Top 3",
    "Others"
)

Identifies the top three ranked employees.
